# Build My Billing Points APK

GitHub Actions workflow: `.github/workflows/build-apk.yml`

IMPORTANT: this starter project does not contain Gradle Wrapper files (`gradlew`, `gradlew.bat`, and `gradle/wrapper/*`). Add those standard wrapper files before running the workflow.

Then on GitHub:
1. Open Actions.
2. Select Build Android APK.
3. Tap Run workflow.
4. Open the completed run.
5. Download `MyBillingPoints-debug-apk`.
